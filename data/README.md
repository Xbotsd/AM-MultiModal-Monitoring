# Data

The datasets are not committed: the acoustic set alone is 4.5 GB, and both sets are
third-party with their own licences.

## Datasets

### EPFL acoustic emission

> *Optimizing In-situ Monitoring for Laser Powder Bed Fusion Process: Deciphering
> Acoustic Emission and Sensor Sensitivity with Explainable Machine Learning*
> Zenodo, [10.5281/zenodo.10449883](https://zenodo.org/records/10449883), CC BY 4.0.

Four sets, `D1`–`D4`, each with `rawspace` (waveforms, 31 401 × 5 000 for `D1`) and
`classspace` (labels). Consumed by `CODE/1_acoustic/*` and
`tools/ae_detectability.py`.

Layout expected by the stages:

```
data/epfl_acoustic/Deciphering AE/D1_rawspace_5000.npy
data/epfl_acoustic/Deciphering AE/D1_classspace_5000.npy
...
```

### Cranfield laser ultrasound

> doi:[10.17862/cranfield.rd.15190191](https://doi.org/10.17862/cranfield.rd.15190191)

Full-matrix-capture array data (`.mat`), used by `CODE/2_laser_ultrasound/*`.

```
data/laser_ultrasound/201120_Ti_FMC_128ave.mat
data/laser_ultrasound/X_lu.npy            # derived features, regenerated by prepare_lu_v3
```

## Derived working data

Stages write intermediate arrays and results into `data/<module>/`. These are
regenerable and are not committed either. The two exceptions committed to the
repository are small summaries:

* `results/ae_d1.json` — the transient detectability table in the README.

## Placing the data

```bash
mkdir -p data/epfl_acoustic data/laser_ultrasound
# unzip the Zenodo archive into data/epfl_acoustic/Deciphering AE/
# copy the Cranfield .mat into data/laser_ultrasound/
python -m ammonitor list        # stages with a leading ! are still missing data
```

`ammonitor list` marks a stage with `!` when a declared input path is absent, and
`ammonitor run` refuses to execute it. Nothing fails silently, and no stage produces
an empty result that could be mistaken for a null finding.

## Provenance of what is computed from these data

See `docs/PROVENANCE.md`. In short: the acoustic and laser-ultrasound classification
stages are process evidence; the fusion and control stages are simulation studies
and are labelled as such in the registry.
