# Data

The datasets are not committed: the acoustic set alone is 4.5 GB, all six sources
together are several gigabytes, and every one is a third-party deposit with its own
licence. Each section below gives the DOI, the licence, the expected layout and the
stages that read it.

`python -m ammonitor list` marks a stage with `!` when a declared input path is
absent, and `ammonitor run` refuses to execute it. Nothing fails silently.

## Datasets

### EPFL acoustic emission — `data/epfl_acoustic`

> *Optimizing In-situ Monitoring for Laser Powder Bed Fusion Process: Deciphering
> Acoustic Emission and Sensor Sensitivity with Explainable Machine Learning*
> Zenodo, [10.5281/zenodo.10449883](https://zenodo.org/records/10449883), CC BY 4.0.
> 4.5 GB.

Four sets, `D1`–`D4`, each with `rawspace` (waveforms; 31 401 × 5 000 for `D1`) and
`classspace` (labels: lack of fusion, conduction, keyhole). Used by the acoustic
classification, ablation, cross-subset, spectral-bound and detectability stages.

```
data/epfl_acoustic/Deciphering AE/D1_rawspace_5000.npy
data/epfl_acoustic/Deciphering AE/D1_classspace_5000.npy
... (D2–D4)
```

Stages: `1_acoustic:*`, `run_epfl_cross_subset`, `tools/ae_detectability.py`.

### Cranfield laser ultrasound — `data/laser_ultrasound`

> doi:[10.17862/cranfield.rd.15190191](https://doi.org/10.17862/cranfield.rd.15190191),
> Cranfield Online Research Data. 45 MB.

Full-matrix-capture laser-induced phased-array data of a wire-arc additive
Ti-6Al-4V component, 68 elements, 4 624 A-scans of 1 000 samples at 20 MHz.

```
data/laser_ultrasound/201120_Ti_FMC_128ave.mat
data/laser_ultrasound/X_lu.npy        # derived features, regenerated by prepare_lu_v3
data/laser_ultrasound/y_lu.npy
```

Stages: `2_laser_ultrasound:*`, `3_fusion:run_sensitivity_full`.

### ORNL Peregrine coupon table — `data/peregrine`

> *Coupon-level features and code for build-held-out evaluation of in-situ
> tensile-property prediction in laser powder bed fusion (Peregrine v2023-11)*
> Zenodo, [10.5281/zenodo.23727492](https://zenodo.org/records/23727492), CC BY 4.0.
> 10.7 MB as one CSV.

Per-coupon features from five builds — DSCNN segmentation fractions, two coaxial
camera channels and machine telemetry — joined to the destructive tensile test.
6 376 coupons carry an ultimate tensile strength. This is the only source here that
pairs process data with a destructive truth, which is why the fusion and graded
decision analyses use it.

```
data/peregrine/peregrine_v2023-11_coupon_features.csv
```

Stages: `7_measured_real:run_fusion_real`, `7_measured_real:run_decision_real`.

### Fringe-projection capture — `data/fringe`

> *Data underlying the article "Fringe projection profilometry with a reconfigurable
> integrated photonic circuit"* Zenodo,
> [10.5281/zenodo.22125908](https://zenodo.org/records/22125908), CC BY 4.0.
> 41 MB extracted (`3D_sample_data.zip`).

Phase-stepped fringe acquisitions of a printed sample, with a calibration-plane
acquisition for carrier removal and an independent PUMA reconstruction that serves
as the unwrapping reference.

```
data/fringe/3D_sample_data/3D_sample_acquisition.tif
data/fringe/3D_sample_data/plane_calibration_acquisition.tif
data/fringe/3D_sample_data/3D_sample_PUMA_reconstruction.tif
```

Stages: `7_measured_real:run_unwrap_real`.

### White-light interferometry height maps — `data/hm`

> *NSF Future Manufacturing Data Challenge: a multimodal DED dataset for
> probabilistic local geometry prediction in laser tracks* Zenodo,
> [10.5281/zenodo.21285367](https://zenodo.org/records/21285367), CC BY 4.0.
> 1.0 GB extracted (`height_maps.zip`).

White-light interferometry of four real SS316L directed-energy-deposition single
tracks, 480 × ~20 000 px at 3.982 µm. No defect labels are published with them, so
the geometric module reports an operating point rather than a recall.

```
data/hm/Heightmap_8.ASC
data/hm/Heightmap_10.ASC
data/hm/Heightmap_14.ASC
data/hm/Heightmap_21.ASC
```

Stages: `7_measured_real:run_pointcloud_real`.

### X-ray CT stack, AlSi10Mg — `data/xct`

> *Tomographic image stacks for the study "Analysis of Porosity in AlSi10Mg Using
> Tomographic Image Processing"* Zenodo,
> [10.5281/zenodo.17602110](https://zenodo.org/records/17602110), CC BY 4.0.
> 127 MB for the primary volume, about 600 MB for all three reconstructions.

DICOM slices of laser-powder-bed AlSi10Mg: 212 slices, 672 × 465 px, 37.0 µm
isotropic voxels. Used to measure the clutter inflation `κ` that makes the
white-noise bound slack on a real reconstruction.

```
data/xct/vol_gd/*.dcm     # primary volume, 212 slices
data/xct/vol_g1/*.dcm     # optional: two further reconstructions of the same material
data/xct/vol_g2/*.dcm
```

Stages: `7_measured_real:run_xct_clutter` (primary volume). The cross-reconstruction
comparison is in the `detectability-bound` repository, which owns the XCT estimator.

## Derived working data

Stages write intermediate arrays and results into `data/<module>/`. These are
regenerable and are not committed. The working directories are `data/output/`,
`data/sensitivity/`, `data/statistics/`, `data/fusion/`, `data/phase_unwrap/`,
`data/pointcloud/`, `data/closed_loop/`, `data/complexity/` and `data/figures*/`;
they hold outputs, not inputs. The committed summaries are the small result files in
`results/`:

| file | produced by |
|---|---|
| `results/ae_d1.json` | `tools/ae_detectability.py` |
| `results/ae_spectral.json` | `CODE/1_acoustic/run_ae_spectral.py` |
| `results/fusion_real.json` | `CODE/7_measured_real/run_fusion_real.py` |
| `results/decision_real.json` | `CODE/7_measured_real/run_decision_real.py` |
| `results/unwrap_real.json` | `CODE/7_measured_real/run_unwrap_real.py` |
| `results/pointcloud_real.json` | `CODE/7_measured_real/run_pointcloud_real.py` |
| `results/xct_clutter.json` | `CODE/7_measured_real/run_xct_clutter.py` |
| `results/stage_prepare_lu_v3.json` | `CODE/2_laser_ultrasound/prepare_lu_v3.py` |

## Placing the data

```bash
mkdir -p "data/epfl_acoustic" data/laser_ultrasound data/peregrine \
         data/fringe data/hm data/xct
# unzip the Zenodo archive into "data/epfl_acoustic/Deciphering AE/"
# copy the Cranfield .mat and the derived .npy files into data/laser_ultrasound/
# copy the Peregrine CSV into data/peregrine/
# unzip 3D_sample_data.zip into data/fringe/ and height_maps.zip into data/hm/
# copy the 212 DICOM slices into data/xct/vol_gd/
python -m ammonitor list        # stages with a leading ! are still missing data
```

Each measured stage also accepts `--data-root`, the directory that plays the role
of `data/`, so a dataset kept elsewhere can be used without moving it:

```bash
python CODE/7_measured_real/run_fusion_real.py --data-root /path/to/data
```

## Provenance of what is computed from these data

See `docs/PROVENANCE.md`. In short: the acoustic, laser-ultrasound, fusion,
unwrapping, geometric, graded-decision and XCT stages are process evidence; the
simulated fusion, unwrapping, point-cloud and control studies remain method
evidence and are labelled as such in the registry.
